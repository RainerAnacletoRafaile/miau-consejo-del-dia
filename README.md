# MIAU Consejo del Día 🐾

Aplicación web personal y responsive construida con React + Vite.

## Módulos
- **Inicio:** bienvenida y acceso a Mi Día.
- **Mi Día:** selección de una emoción y un único consejo diario.

## Regla del consejo diario
La primera emoción seleccionada genera un consejo y lo guarda en LocalStorage. Durante el mismo día, volver a entrar mantiene la misma emoción y el mismo consejo. No hay botón para generar otro consejo. Al cambiar la fecha local del dispositivo, se habilita una nueva elección.

## Tecnologías
- React
- Vite
- JavaScript
- CSS
- LocalStorage

## Desarrollo local
```bash
npm install
npm run dev
```

## Compilación
```bash
npm run build
```
